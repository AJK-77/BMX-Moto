## Werkgebied

## Icons

De GUI maakt waar mogelijk gebruik van algemeen herkenbare symbolen.

Er worden geen eigen symbolen ontworpen wanneer hiervoor een algemeen geaccepteerd alternatief bestaat.

Voorbeelden:

- Batterij/Opladen
- Draadloze verbinding (WiFi-symbool)
- Waarschuwing
- Instellingen
